# eli5

Explain any topic like I'm 5.

```
/eli5 how does DNS work
```

Produces an HTML explainer with big pictures and very few words that explains the topic to someone who knows nothing about it.

Works in Claude chat, Claude Cowork, and Claude Code. In chat you can also just say
"ELI5 how DNS works" — the skill triggers from its description. See the
[repository README](../../README.md) for install steps on each surface.

Originally from [anthropics/claude-plugins-community](https://github.com/anthropics/claude-plugins-community/tree/main/eli5) by Thariq Shihipar (MIT).
